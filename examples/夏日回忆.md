# 夏日回忆

标题: 夏日回忆
简介: 高一最后一个学期，转学生小美搬进了隔壁班。某个慵懒的午后，她在天台等你。这是只属于你们两个人的夏天。

## 角色
小美: img_human/mei.png @ right
小明: img_human/ming.png @ left

## 背景
教室: img_bg/classroom.png

## 剧本
[bg 教室]
[bgm audio/bgm_school.mp3]
小明: 唉，又是无聊的数学课……
小美: 喂，你就是小明吧？听说你作文写得不错？
小明: 啊？是、是吧……
（小美把一张纸拍在课桌上）
小美: 帮我写一首诗！这是委托！
小明: 诶——为什么是我啊！
[变量 好感度 0]
[选项]
- 接下委托 → 天台线
- 委婉拒绝 → 教室线

### 天台线
[bg 天台]
[bgm audio/bgm_roof.mp3]
[show 小美 @ center]
[变量 好感度 + 1]
小明: 所以……为什么非要我写诗？
小美: 因为我要转学了。想给这个学校留下点什么。
小明: 转学？！
小美: 嗯，下周就走。所以，拜托了——写一首关于夏天的诗。
（风把她的刘海吹起来，她笑了笑）
[if 好感度 >= 1]
小美: 你果然愿意来。谢谢你，小明。
[endif]
[bgm off]
[结束 结局·天台上的诗]

### 教室线
[bg 教室]
小明: 那个……我还是不写了，怕写不好。
小美: 哼，胆小鬼。那我自己写！
（她抢过纸笔，趴在桌上认真地写了起来）
小美: 写好了！你看——「夏天把我们的影子拉得很长，长到可以走到未来」。
小明: （这家伙……明明自己就会写嘛）
[if 好感度 >= 1]
小美: 下次……再听你念诗吧。
[else]
小明: 那个……等你转学之前，我也写一首送你吧。
[endif]
[bgm off]
[结束 结局·认真的午后]
